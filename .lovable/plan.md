# To My Bachcha ♡

## What I’ll build
- Three client-side pages: the playful question, the full letter, and the warm ending.
- A handmade cream-and-rose visual system with paper texture, serif letter typography, handwritten accents, and subtle hearts.
- The seven-step shrinking and moving NO interaction, plus the opening-envelope YES transition.
- Scroll-based paragraph reveals on the letter page and a gentle transition into the ending page.
- An unobtrusive music control that remains disabled until a real audio file is available, without embedding copyrighted music.

## Technical details
- Keep the existing React and TanStack setup, using three proper routes with no page reloads.
- Use lightweight CSS animations and Intersection Observer with reduced-motion support.
- Preserve the supplied letter copy exactly and add unique metadata for all three pages.
- Verify desktop and mobile layouts, navigation, overflow, and browser console output.
